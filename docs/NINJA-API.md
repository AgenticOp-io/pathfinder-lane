# NinjaOne integration

**Role:** Inventory — device IPs for SSH.

Sync into `Customers/<client>/Ninja/`. OAuth client credentials in Settings → Tools.

File → **Sync devices from NinjaOne…**

Env: `NINJA_CLIENT_ID`, `NINJA_CLIENT_SECRET`, `NINJA_BASE_URL`

Pair with a documentation vault for credentials. See [MSP-INTEGRATION-STACK.md](MSP-INTEGRATION-STACK.md).
