# Upstream PathfinderSSH engine

Pathfinder Lane is a **GPL-3.0 derivative** of Scott Peterman’s [PathfinderSSH](https://github.com/scottpeterman/pathfinderssh).

| | |
|--|--|
| **Upstream repo** | https://github.com/scottpeterman/pathfinderssh |
| **Product repo** | https://github.com/AgenticOp-io/pathfinder-lane |

## What upstream owns

Core terminal, crawl, capture, map, YAML session tree, encrypted vault, and the click-to-connect loop. MSP work layers customer inventory, integrations, auth, and packaging on top — see [MSP-SYNOPSIS.md](MSP-SYNOPSIS.md).

## Portable fixes

Changes that benefit all PathfinderSSH users should be offered upstream via PR. See [CONTRIBUTING.md](CONTRIBUTING.md).

## Engine internals

For crawl, SSH, shell, capture, and vault internals, read the upstream repository and its architecture notes. This MSP fork does not mirror those documents — they live with the engine author.
