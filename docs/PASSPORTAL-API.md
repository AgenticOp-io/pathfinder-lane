# Passportal integration

**Role:** Credentials — N-able Passportal passwords into vault.

File → **Import credentials from Passportal…** Enter customer folder name for session linking.

Settings → Tools: API key, optional tenant, base URL.

Env: `PASSPORTAL_API_KEY`, `PASSPORTAL_TENANT`, `PASSPORTAL_BASE_URL`

See [MSP-INTEGRATION-STACK.md](MSP-INTEGRATION-STACK.md).
