# ConnectWise Manage integration

**Role:** Customers — creates `Customers/<name>/` folders from PSA companies.

Settings → Tools: company ID, public/private keys, API base URL.

File → **Sync customers from ConnectWise…**

Env: `CONNECTWISE_COMPANY_ID`, `CONNECTWISE_PUBLIC_KEY`, `CONNECTWISE_PRIVATE_KEY`, `CONNECTWISE_CLIENT_ID`, `CONNECTWISE_BASE_URL`

Then sync inventory and credentials per client. See [MSP-INTEGRATION-STACK.md](MSP-INTEGRATION-STACK.md).
